# TestNG + Assertions + Data-Driven Testing — Starter

Project ini adalah starter untuk assignment Test Runner dan Data Driven.

## Target
- Integrate TestNG
- Hard Assert
- Soft Assert
- Selenium login test
- Read test data from Excel using Apache POI
- TestNG DataProvider
- testng.xml
